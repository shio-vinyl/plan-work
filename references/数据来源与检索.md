# 数据来源与检索

## 来源优先级

1. **项目材料**：甲方给的表、已定的规划成果。
2. **政府官网正式发布**：区、市政府网站的统计信息、政策文件、通知公告。
3. **统计出版物**：统计公报（年度）、经济运行情况（月度、季度累计）、统计年鉴（分区表里常单列各区）、经济普查公报、人口普查公报。
4. **部门公告的附件**：配租配售公告的房源表、等级评定公示、补贴发放方案（常附企业和项目清单）、法治政府建设报告（常有工单、信访数）、在线访谈。
5. **媒体报道**：只在前四类没有时用，注明“媒体转述”。

## 国内政府网站怎么查

政策、公文、标准规范和规划公示公告的系统查法、七条规划检索轨道、防踩坑禁令与降级路径，见 `政策与公文检索.md`。本节保留公开数据检索的要点：

- **境外搜索引擎基本搜不到区级政府网站**，`WebSearch`、`WebFetch` 对基层公告常失败，且 `WebFetch` 不适合逐字核公文或拉 PDF。本机直连优先用 `python3 -I scripts/govdoc.py`（全国通用脚本：`central` 查中国政府网、`std` 查行标/地标、`search` 走国内搜索 API、`list` 翻栏目、`fetch --archive` 校验抓取并归档、`extract` 解 OFD/PDF/WPS/RAR）。
- **站内搜索与栏目翻页**：先找栏目页（如统计信息、政策文件、通知公告、政府公报、法治政府建设报告），用 `python3 -I scripts/govdoc.py list` 顺着栏目翻页，常比关键词搜得全；广东站群还支持 `gkmlpt` 信息公开目录 JSON。
- **轻量单功能脚本**：仅查广东省政府网站群或抓取单个页面时，也可用 `scripts/gov_search.py`（`search.gd.gov.cn/jsonp/sites`，严禁枚举站点 ID 段以防 403 限流）与 `scripts/gov_fetch.py`。
- 检索词用标题里会出现的正式说法：“统计公报”“经济运行情况”“配租”“等级评定”“发放方案”“管理办法”。只搜标题噪声小。

## 统计口径陷阱

| 情况 | 处理 |
|---|---|
| 统计常住人口和规划、管理人口差很多 | 两个都写，标明口径；规划测算沿用规划口径 |
| 初步数和修订数（经济普查后会修订 GDP） | 写明用的是哪个；做增速时同一口径 |
| 公报数和年鉴数不同 | 年鉴是终核数，优先用年鉴；公报数标“初步” |
| 累计同比（1—4 月、1—8 月） | 写明时点；时点不同的数不放在一起比 |
| 总产值和增加值、规上和全部 | 名称照原文写全 |
| 年鉴里的“二级市场” | 指新房交易；二手房是“三级市场” |
| 预计数、计划数 | 照原文写“预计”“计划” |

## 状态五类

| 状态 | 含义 | 下一步 |
|---|---|---|
| 可用 | 有正式出处，口径清楚 | 直接用 |
| 待核 | 有线索，但出处或口径还没确认 | 去原文核 |
| 有误 | 和正式出处对不上 | 改，并在底稿里写明原数和正确数 |
| 无出处 | 找不到任何来源 | 删掉，或者改成定性表述 |
| 缺 | 要用，但现在没有 | 写明找过哪里；定是用假设、定性表述，还是如实写缺 |

## 记录格式

工作底稿里单列一页“公开数据”：

| 类别 | 数据项 | 时点 | 数值 | 口径 | 来源 | 链接 | 核验 |
|---|---|---|---|---|---|---|---|

- 数值照原文抄，不四舍五入。
- “核验”列只在主会话亲自打开原文核过时填“已核”。
- 数据清单另一页按“要用的数”组织：数据项、状态、底稿写法、可靠来源的数、来源、下一步。

## 存原件

年鉴、公报、附件表下载后存进项目的 `原始资料/网上公开资料/`，文件名写来源和日期。子 agent 下载的文件在临时目录，会话结束可能被清掉，主会话挑出有用的存进项目。
