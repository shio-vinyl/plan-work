# 写作语言

规划文本、专题研究、汇报稿共用的语言规则。读者是没参加过我们讨论的主管部门、评审和同事。文本怎么搭、每节写什么见 `专题和文本结构.md`。

## 三种惯性

模型起草的规划文本，大多数毛病出自三种惯性。三种都是想显得严谨、有关联，结果都是读者分不清一段在讲什么。

| 惯性 | 表现 | 例子 | 改法 |
|---|---|---|---|
| 挂钩 | 每写一样东西，马上接一句把它和别的东西连上 | 引文后接“落到本地”；原则后接“本地按……”；形势后补细节；“详见专题×” | 让结构承担关联：本地怎么落，写在它该在的节 |
| 防御 | 怕被误解、怕被挑错，追加澄清和限定 | “本文所称……只指”“比××宽”“但××只计……”“不重复统计” | 让第一次定义承担口径：说清一次，后面不再追加 |
| 讲文件 | 主语是文件、关系、抽象概念，没在讲事 | “均出自这一规划”“分别对应”“A决定了B”“测算链” | 让句子只讲事：写成谁做什么 |

下面三节分别展开。

## 不旁征博引

怕显得空泛，就在每样东西后面马上接一句，把它和别的东西挂上钩：引一句上位文件，接一句“落到本地是……”；说一条原则，接一句“本地按……”；写一个数，接一句“这说明……”；段尾再接一句“详见……”。每句单看都有理，连起来就是这一句插一句。

- **一段只讲一类东西。** 文件说了什么、本地现在怎么样、本地要怎么做，各有各的节（见 `专题和文本结构.md` 第 3 节）。一段里混了两类，后一类多半是插进去的，删掉或挪到它该在的节。
- **相关性靠选材和结构，不靠按语。** 只引和本项目直接相关的条款，就已经说明了相关；不要在每条引文后面补一句来证明它有用。
- **借用成果说法的段落，不再往后补。** 例如发展形势照汇报稿写了“交通区位持续改善”，后面不再接某块新出让地块离站点多近；写了“产业集聚带来新需求”，不再接新增人口和投产年份。
- **内容本身就是本地的，可以直接写。** 本级规划对本地的要求、上位文件点名本地的原句，本来就在讲本地，照写，主语写出来（“××区……”）。
- **不写“详见××”“见××”。** 读者要找自然会去看对应章节；专题之间的分工只在总括专题开头交代一句。
- **检验：** 逐段问“这段在讲哪一类”。答不出一类的，找出插进去的那句。段尾出现“落到本地”“对应”“据此”“这说明”“体现了”“详见”时，先怀疑它是插进去的。

## 不写防御性用语

- **工作状态不进正文。** 待补、待核、待定、口径说明、“仅供参考”“以……为准”“尚未见公开数据”，不进正文和汇报页面。缺的内容直接不写，要说明的放备注或工作底稿。数据来源可以作为表注写。
- **怕读者理解错而补的话也算。** “但××只计……”“分口径测算、不重复统计”“需要注意的是……”。口径在第一次出现时说清一次，后面不再追加澄清。
- **口径定义写成概括、定性的句子。** 写“本地已形成保障性住房、产业宿舍和安置房三类保障房”，不写“本地口径比××宽”“本文所称……只指”。

## 写成谁做什么

逐句问：这句的主语是不是做事的人或事（规划、部门、项目、某类住房），动词后面是不是直接接内容？主语是文件之间的关系、抽象的节奏或比例，这句就是在讲文件、讲道理，没在讲事。读着像论文，多半是这个原因。

| 写法 | 例子 | 改法 |
|---|---|---|
| 回指、交代出处 | “十四五”的人口、住房、用地和资金指标均出自这一规划；落实的就是这一要求；作为……的依据 | 倒过来写成动宾：规划确定了“十四五”人口、住房、用地和资金四方面的指标；年度计划按……调整…… |
| “分别对应”讲文本结构 | 发展策略分三个方面，分别对应发展目标中三方面的要求 | 直接写关系本身：按……的目标，策略分三个方面 |
| 抽象名词作主语的因果句 | 人口导入的节奏决定了保障需求释放的快慢；能否兑现取决于能否开工 | 写成谁按什么做：保障性住房按人口导入的实际节奏分期投放；推动项目按期开工 |
| 名词化 | ……是“好服务”的承担者；存在时间上无法及时供应的错位 | 还原成动词：物业服务承担“好服务”；安置房在时间上无法及时供应 |
| 固定开头 | 每条都以“落到本地，……”开头；每节都以同一句“本专题坚持……按三步开展”开头 | 去掉固定开头，直接以“本地……”或动作起句；必须保留的开头句，后半句按本节内容写实 |
| 后一节复述前一节 | 研究思路开头写“按技术路线的三步，先……再……最后……” | 删掉，下面的小节自己会说 |
| 点名过程材料、自造术语 | 按审议稿指标说明；沿用测算链 | 照规划正式名称或“规划编制成果”写；“测算方法” |

- **一条装了几件事，先点明几个方面。** 例如“从‘好房子’、完整社区和城市更新三个方面提升住房和社区品质”，再用“一是、二是、三是”分写。分类的数目要和后文对上：写了“分两类”，后面就不能出现第三类；三条策略也不能说成“分别对应四个环节”。
- **检验：** 把句子里的“这一”“对应”“决定了”“体现在”“作为……的依据”圈出来，每处都试着改成“谁＋动词＋内容”。改完意思不变、句子更短的，就用改后的。

## 不当讲解员

和“讲文件”同源：句子不讲事，在对读者说话。逐句问：这句在说项目和政策本身，还是在告诉读者这段讲什么、该怎么看？后者删掉。

- 不写解说句式：X 回答 Y、要解决什么、从……看、靠的是、要做的是、让……、把……变成。
- 不写读法说明：怎么查、下表是、本节主要研究以下四个问题。
- 研究问题本身可以用问句。

## 本地化

- **检验：** 把地名换成另一个城市，这段话还成立的，就是放之四海皆准的写法。要换成本地的事实（数字、项目名、片区名）、本地的问题（为什么会这样）和本地的做法。
- 研究思路、技术路线写这个项目实际怎么做，不写放哪都成立的方法论。
- 本地化靠选材和后文的研究思路、策略，不靠在每条政策后面接一句本地的事（见“不旁征博引”）。

## 政策和提法

政策背景和提法最容易写成放之四海皆准，也最容易被评审挑出和上位不一致。做法见 `上位依据与对齐.md` 第 6 节（提法库）。

- **提法分层用。** 上位定式（中央、部委文件的原句）照原文，不增减字；本市通行的写“落实××市……”，不说成本区自创；本区已定的照规划成果或本区纲要；材料之间有分歧的列出来问；过时的和自造的不用。
- **核时效。** 提法以最新的中央文件为准。某个提法在近两三年的中央文件里不再出现（比如“房住不炒”），专题不主动写，阶段成果已有的不改，告诉用户。
- **拼接、化用的不照搬。** 汇报稿里常把两处原话拼成一句，引用时找到原句分开写。
- **写法全文统一。** 同一提法只用一种写法（顿号、加号、语序）；短提法加引号；数字串提法第一次出现写清各指什么。
- **政策背景分层写。** 按国家、省、市、区排，每层只引和本专题直接相关的一两条；上位文件点名本地的那句照引。“对照上位要求，本地还差什么”放进研究基础或问题里写。
- **上位提法放在背景、原则和结论里。** 具体做法里写对象、项目和做法，少用口号。
- **不另造数字纲领和品牌名**（“一主两优三提升”“××有家”），除非用户要；这类提法在区级稿里多半只出现一次、没有对应的指标和项目，显得空。
- **拟制定的文件写“制定”，不写“落实”。** 未正式发布的上位文件怎么注状态，见 `上位依据与对齐.md` 第 4 节。

## 标题和分条

- 标题有成果或合同原文的用原文；没有原文的用中性、定义性的名词。不写 PPT 式“主题：判断句”的冒号标题。小标题按内容量选：内容多用名词（基本情况、存在问题、案例做法），内容少就不要小标题。
- **口号式标题的例外：** 用自己的短提法把成果已有内容梳理成整齐一组、不另作解释时可以用（例：“以产定类、以产定位、以产定序”），每组紧跟一句定义。
- 分序号结构化写：“（1）引领短语。正文……”，不写推进式长段；引领短语也守上面的标题规矩。
- **判断式引领短语下只放能支撑它的内容。** 例：“市场总体稳中有控”下写房价和市场规模，不放宣传活动和首付政策；支撑不了的另起一条。
- **条目里要引文件规定的，先交代出处。** 在分条前用一句说明是哪份文件规定了什么，条目里直接写内容，不用“按××办法，……”起句。
- 先下判断再举个案的，个案前加“例如”或“如”；列举做法、交代构成时不加。

## 用词

常见的 AI 味：

| 写法 | 例子 | 改法 |
|---|---|---|
| 造“X位一体”“闭环” | 四位一体、六位一体、全闭环技术路径 | 直接写是哪几件事 |
| 口号和比喻 | 深水区、第一基础设施、纸上画画墙上挂挂 | 写事实和判断 |
| 引号新词 | “增量优化与存量提质”协同的总体方位 | 用文件里已有的正式说法 |
| 每段结尾升华 | ……为高质量发展提供坚实支撑 | 删掉 |
| 不是 X 而是 Y | 不是孤立章节，而是有机组成 | 直接写 Y |
| 第一人称表态 | 我们明确要求 | 写成“新建住宅执行……” |
| 堆形容词 | 精准、深度、全面、系统、高效 | 每句最多保留一个，最好换成数 |

不压字、不自造：

- 动词用双音节：调整为、转换为、办理、适用于、涉及、确定。
- 缩略只用文件或行业已有的说法（控规、工改工、公配、商办、保租房），不为省字现场造词；缩略不能改掉原意（原文“集中供应了一批农房”，不能缩成“农房集中审批”）。
- 引申搭配只用原文已有的：原文的“保障托底”可以照用，自己引申成“托底居住品质”就不行。
- 不省用地类型、对象和主体。
- 一句只说一件事。放不下时少说一件事，不压词。
- 讨论用的口语不上文本：走、动了、查、管、碰红线、起步、跟不上、发力、又大。

## 数字

- 写明时点和口径：“2025 年末常住人口 12.6 万人（统计口径）”。同一个量全文只用一个口径。
- 同一个数全文一致；合计、分项要对得上。
- 指标数字前写指标名（“新增商品住房建筑面积总量[120]万平方米”），结论、小结里也不省成“[120]万平方米”。
- 推算的数写明算法，或放进附表。

## 汇报稿和文本的差别

| | 汇报稿 | 文本、专题 |
|---|---|---|
| 结构 | 分级标题的树，一页一个叶节点 | 外壳可沿用，内部按技术路线、原则、研究思路、结论一条线串；方面取合同原话（见 `专题和文本结构.md`） |
| 强调 | 每页一行红字结论；整块实色、大字放大两三件重点；次要信息不删少 | 段首主句写判断，不加粗堆砌 |
| 图表 | 图示代替表格，表格只用于清单和逐行比对 | 表格可以多，表前一句写结论 |
| 过程信息 | 放备注 | 放工作底稿，不进文本 |

## 公文版式（政策条款类 Word）

标题方正小标宋简体；正文仿宋_GB2312 三号；一级标题黑体，二级标题楷体_GB2312。版面和页码的核对见 `文件组织.md`“Word 成果”。

## 自查清单

定稿前过一遍：

1. **溯源：** 每条策略、结论分成成果原有、其他已有材料、自己提出三类，看比例；逐条核自提的有没有和原文冲突、有没有写硬（见 `专题和文本结构.md` 第 4 节）。
2. **逐段问“这段在讲哪一类”：** 答不出一类的，找出插进去的那句。
3. **圈词：**
   - 挂钩：“落到本地”“据此”“这说明”“体现了”“详见”；
   - 防御：“只指”“只计”“不含”“不重复”“需要注意”；
   - 讲文件：“这一”“对应”“决定了”“取决于”“作为……的依据”。
   每处试着删掉或改成“谁＋动词＋内容”。
4. **换地名：** 把地名换成别的城市，还成立的话不写。
5. **核数：** 指标数字带名字，口径只有一套，合计和分项对得上。
