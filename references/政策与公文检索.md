# 政策、公文与公告检索

查上位政策、部委文件、地方规范性文件、规划公示公告、标准规范和外地对标案例时，按本文操作。统计口径与公开数据登记仍见 `数据来源与检索.md`。

## 1. 工具分工

- **优先用 `scripts/govdoc.py`**（本 skill 内置的全国规划特化检索脚本，统一用 `python3 -I scripts/govdoc.py <子命令>` 运行，零外部 Python 依赖；国家级库与抓取解析均无需 API Key，配置国内搜索 API Key 后支持全国泛搜）：
  - `python3 -I scripts/govdoc.py central`：零 Key 直查中国政府网政策文件库（国务院文件、部委文件、国务院公报、官方解读），带文号、发文机关、发布日期。
  - `python3 -I scripts/govdoc.py std`：零 Key 直查全国行业标准（`TD/T`、`CJJ`/`JGJ` 等）与地方标准（`DB*`）及其现行/废止状态。
  - `python3 -I scripts/govdoc.py search`：全国规划特化搜索（接入百度千帆 `BAIDU_QIANFAN_API_KEY`、博查 `BOCHA_API_KEY` 或阿里云 `ALIYUN_IQS_API_KEY`，优先读进程环境变量，缺省时自动读仓库外的 `~/.config/govdoc/env`；按规划轨道自动限定四部门官方域并做五级信源打标；无 Key 时可用 `--dry-run` 查看路由与建议检索词）。
  - `python3 -I scripts/govdoc.py list`：政府网站栏目翻页器（支持全国静态分页栏目和广东 `gkmlpt` 信息公开目录 JSON）。
  - `python3 -I scripts/govdoc.py fetch`：强校验抓取正文与附件（检查 HTTP 状态码和文件头魔数防假 PDF、自动识别 UTF-8/GB18030、抽国办 `<meta>` 与文号/日期/效力、发现图片类规划附件、一键按本工作流规范归档）。
  - `python3 -I scripts/govdoc.py extract`：解析本地 `.ofd`、`.pdf`（自动检出无文字层扫描页）、`.docx`、`.doc`/`.wps`/`.et`、`.rar`/`.7z`/`.zip`。
  - `python3 -I scripts/govdoc.py sites` / `probe`：查看已配置轨道与提供方状态、单次探测官站 `<meta name="SiteIDCode">`、将自定义地区官站沉淀到本机 `~/.config/govdoc/sites.json`（不写入仓库）。
- **轻量单功能脚本**：仅需极简调用广东站群搜索或单页抓取时，也可用 `scripts/gov_search.py` 与 `scripts/gov_fetch.py`。

## 2. 七条规划检索轨道（按任务选渠道）

| 轨道（`--track`） | 适用场景 | 优先路径 |
|---|---|---|
| `upper-policy` | 国家/省/市/区上位政策、五年规划纲要、政府工作报告、政府公报 | 国家级先 `govdoc.py central`；地方用 `govdoc.py search --track upper-policy --region <地名>`，优先找政府公报和规范性文件库 |
| `spatial-plan` | 国土空间总规批复与文本、控规/详规草案与批后公告、法定图则、用地混合/用途转换 | 锁定自然资源部及省市规资局；抓完必查图片/展板附件和“本文有删减”字样 |
| `housing-renewal` | 住房发展规划、保障房配租配售公告、城市更新计划与专规、老旧小区、物业与绿建 | 锁定住建/房管/更新局与区政府公告栏；**按时间倒序串全生命周期**（意愿→计划草案→计划公告→规划草案→批复→许可），防止拿旧草案当现行版 |
| `land-supply` | 年度供地计划、土地招拍挂出让与成交公告、规划设计条件、基准地价 | 锁定本地规资局与公共资源交易中心；中国土地市场网和全国公共资源交易平台有动态签名与频控，不写爬虫硬刷，批量宗地留给浏览器或人工导出 |
| `stats-census` | 统计公报、统计年鉴、月/季经济运行、人口普查、经济普查、法治政府建设报告 | 优先找统计公报和年鉴原件 PDF（国家统计局数据中心直连接口有 WAF 限制，不直接抓接口）；区级工单与信访数常在法治政府年度报告里 |
| `standards` | 国标、行标、地标及城市规划技术准则（`GB`、`TD/T`、`CJJ`/`JGJ`、`DB*`） | 行标和地标先用 `govdoc.py std "<词>" --kind hb,db [--area 省市]`（地标接口需单关键词加 `--area`）；国标经搜索 API 限定住建部/自然资源部/国标网查 |
| `benchmark` | 外地对标政策与实践（如北上广深津等横向调研） | 支持 `--region 北京,上海,广州` 多城展开，优先拿规范性文件正文和附表（正负面清单、比例表），区分原文、解读与媒体报道 |

未收录进内置站点表的任意地级市、县或新区，`python3 -I scripts/govdoc.py search --region <地名>` 会自动走全国 `gov.cn` 泛化路由；命中官站后可用 `python3 -I scripts/govdoc.py sites add` 沉淀到本机 `~/.config/govdoc/sites.json`。

## 3. 五级信源与引用口径

| 等级 | 范围 | 用法 |
|---|---|---|
| `T1_central` | 中国政府网、国务院各部委、全国人大、司法部、全国标准信息服务平台 | 权威原文，直接采信 |
| `T2_local_gov` | 省市区政府门户、政府公报、规资/住建/发改/统计部门官网 | 权威原文，优先政府公报和规范性文件库 |
| `T3_public_platform` | 公共资源交易中心、一体化政务服务平台 | 交易与公示正式出处 |
| `T4_state_media` | 新华社、人民日报、中国建设报等官媒 | 仅在官网无原文时作佐证，标注来源 |
| `T5_media_repost` | 商业媒体、房产网站、公众号、咨询机构、第三方转载站 | **只能作线索或注明“媒体转述/非官方转载”**，状态记“待核”，不得冒充官网原文 |

## 4. 硬禁令与防踩坑清单

1. **绝不裸 `curl` 爬国内通用搜索引擎**（如必应国内版、百度网页）：常静默返回完全无关的广告页或错误结果。
2. **绝不暴力枚举站点 ID 段**：对广东 `search.gd.gov.cn` 等站群接口连续扫号会直接触发全局 `403` 限流；只用 `python3 -I scripts/govdoc.py probe <首页URL>` 单次查看站点元数据，严禁循环猜 ID。
3. **不用 `WebFetch` 代替公文逐字核对或下载 PDF**：境外节点对区级政务站失败率高，且摘要器会拒绝逐字输出公文原文，拉 PDF 还会返回压缩二进制乱码。拿到官链后一律在本机用 `python3 -I scripts/govdoc.py fetch` 直取。
4. **遇反爬/WAF、单引擎盲区或栏目页的降级路径**：
   - 任何单一搜索引擎都有索引盲区（区县级近期新发文、挂 403/412 墙的县站常漏检）。
   - 命中带 `📂栏目入口页` 标记的结果时，**不要把栏目更新日期当成单文发布日期**，应紧接用 `python3 -I scripts/govdoc.py list <栏目URL>` 展开翻页抓具体文章。
   - 若搜索结果中只有“摘要引文文号”（如挂牌出让公告里顺带引用了某政策文号），不能把该条当成目标政策原文。
   - 遇到 `412`/`521`/`403`（如瑞数/长亭 WAF）或登录墙，脚本立即熔断停手，绝不加伪造头反复硬试；按以下顺序降级：
     - ① 换该站政策/公告栏目页用 `python3 -I scripts/govdoc.py list` 直扫（或切第二个搜索源 `--provider multi` / 宿主搜索交叉补盲） → ② 上级政府门户、政府公报或部门转载页 → ③ 本机交互浏览器人工打开 → ④ 权威媒体转述（明确标“非官方原文/待核”） → ⑤ 如实记入缺口清单并说明试过的站点和关键词。
5. **警惕前端 SPA 空壳**：部分互动/意见征集页（如 `/hdjlpt/yjzj/`）静态抓下来会显示“暂无附件”且正文极短；看到 `NEEDS_BROWSER_RENDER` 提示时，不要误判为“无附件”，改用浏览器打开核实。
6. **区分三个日期**：同一份文件的**成文日期**（落款日）、**发布日期**（官网挂网日）和**媒体报道日期**常差几天到几周，记录和引用时分别写清，避免与既有成果对不上。
7. **效力状态必须核透**：
   - 中国政府网等站点不设效力栏，“未搜到废止文件”**不等于**“已确认现行”；
   - 地方政策大量带 2—5 年有效期或试行期，看到“试行/暂行/有效期×年”必须核对是否到期、是否被新文取代（如发文末尾的“同时废止……”条款）。
8. **警惕删减版与扫描页**：公开版国土空间总体规划常注明“本文有删减”，PDF 末尾附图也常是无文字层扫描页；“全文搜不到某词”时必须先确认不是删减或未 OCR 导致。
9. **规划公告必查图片附件**：控规公示、城市更新公告的核心数据（用地面积、容积率、指标控制图、拆除范围示意图）常在 `.jpg`/`.png` 附件或正文展板图里，抓取公告时加 `--with-images`。
10. **非标格式统一解包校验**：政务附件常见 `.ofd`、`.wps`、`.et`、GBK 中文名 `.rar`/`.zip`，以及表面是 `.pdf` 实为 HTML 报错页的假文件；统一走 `python3 -I scripts/govdoc.py fetch` 校验魔数并用 `python3 -I scripts/govdoc.py extract` 提取，绝不把未校验的文件直接塞进项目目录。

## 5. 归档与核验记录格式

凡要进成果的政策、公文和公告，用 `python3 -I scripts/govdoc.py fetch "<URL>" --archive 原始资料/网上公开资料/<主题_YYYYMMDD> --with-images` 落盘，自动保留：

- 原样网页 `.html`、带 YAML 核验头的清洗正文 `.txt`、`附件/` 原件和 `manifest.jsonl` 索引；
- 项目核对记录表至少包含以下列：

| 文件/公告 | 文号 | 成文日期 | 发布日期 | 效力状态与有效期 | 来源等级 | 附件与删减情况 | 核对结论 | 链接 |
|---|---|---|---|---|---|---|---|---|
